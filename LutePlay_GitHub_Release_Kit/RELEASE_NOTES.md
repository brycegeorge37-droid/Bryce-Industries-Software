# LutePlay 0.1.0-dev — Linux Beta

First packaged **Linux x86-64 beta** from Bryce Industries Incorporated.

Current terminal features include music library browsing, full-folder and full-library playback, global shuffle, volume and mute controls, Sever/Unsever settings, and optional release checks through the Bryce Industries website.

**Downloads**
- `.deb`: installer for compatible Debian/Ubuntu-based systems; requires system VLC.
- `.tar.gz`: portable archive for compatible Linux x86-64 systems; requires system VLC. Extract and run `./run-luteplay.sh` inside the extracted application folder.
- `SHA256SUMS`: checksums for verifying the two downloads.

**Testing status:** Packaged installation and music playback have been tested on the developer's Kubuntu machine. Fresh installations and other Linux distributions still need testing. This is an early prerelease, and the interface is currently terminal-based. Windows and macOS packages are not included yet.

**Updates:** LutePlay currently notifies you when a newer published version is listed; it does not automatically install updates.
